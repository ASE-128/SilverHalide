# Milestone M3 · 内存极致（P-A）

> Status: DRAFT
> Milestone: P-A M3
> Last updated: 2026-09-24

## Scope

本节点承接 **D-1** 与 **D-2** 两条量化锚点：

- **D-1**：**编辑单张 50MP RAW 峰值内存 ≤ **1.2 GB**。**
- **D-2**：**切图后内存回落到常驻基线 ≤ **400 MB**。**

- **Range**：RAW 大图 ≥ **8000×6000（~50MP）**；基准机器 = 目标发布配置（x64，独立 GPU 可选）。
- 对应支柱文档子阶段 **2 内存极致**：峰值内存控制（编辑 50MP 单张全流程）、切图后内存回落策略（释放全尺寸缓冲、清缓存所有者、GC）。
- 主要算力域：engine `ImageBuffer` 全尺寸缓冲生命周期与 LRU 容量策略（256MB）、catalog 磁盘缓存所有者、ui `PreviewWorker` 缓冲持有。

> 锚点来源：master 定位与支柱规格，数字一字不改；仅做节点落地拆解，不新增量化承诺。

## 依赖与上下文

- D-1/D-2 验收校准依赖 1a（M1）的缓冲生命周期；M3 可与 M1/M2 并行推进。
- D-1 内存目标与超分/多份全尺寸缓冲冲突时，以"至多 1 份全尺寸缓冲 + LRU 上限"为准。
- 峰值与回落口径：进程私有内存（WorkingSet / 采样 API），注明口径即可。

## Acceptance criteria

> 二值、可验证；真机与基准机器口径一致，留存实测记录。

- [ ] 编辑单张 50MP RAW 全流程（进 1:1 + 拖若干滑块）的进程私有内存峰值采样：**峰值 ≤1.2GB 实测记录**。
- [ ] 从峰值切到另一张图后，定时（0.5s/1s/2s/5s）采样回落曲线：**切图回落 ≤400MB 且保持的实测记录**。
- [ ] 回落是**可重复**的（非临时命中快照造成的假阴性/假阳性）。
