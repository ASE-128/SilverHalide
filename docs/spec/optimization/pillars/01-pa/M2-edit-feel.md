# Milestone M2 · 编辑手感（P-A）

> Status: DRAFT
> Milestone: P-A M2
> Last updated: 2026-09-24

## Scope

本节点承接 **B-2** 与 **B-3** 两条量化锚点：

- **B-2**：**滑块拖动松手/停顿 → 1920 精帧 ≤ **80ms**。**
- **B-3**：**50MP 连续编辑全程主线程问询 ≤ 16ms/帧（无 UI 卡顿）。**

- **Range**：RAW 大图 ≥ **8000×6000（~50MP）**；基准机器 = 目标发布配置（x64，独立 GPU 可选）。
- 对应支柱文档子阶段 **1b 编辑手感（精帧）**：滑块 coarse-then-refine 的 1920 精帧触发时机（松手/停顿 ≥80ms，即像素截止节流的停顿口径）、精帧渲染耗时、主线程帧预算审计。
- 主要算力域：engine `Pipeline.render` coarse-then-refine 语义、ui `PreviewWorker` 的 coarse/refine 触发与 generation 丢弃过时结果、主线程每帧问询预算审计点。

> 锚点来源：master 定位与支柱规格，数字一字不改；仅做节点落地拆解，不新增量化承诺。

## Acceptance criteria

> 二值、可验证；真机（含独立 GPU 机器）留存实测记录。

- [ ] 脚本化拖动滑块 → 松手计时到 1920 精帧，重复 N 次取稳态：**松手→1920 精帧 ≤80ms 实测记录**。
- [ ] 50MP 连续编辑 ≥10 次调整操作全程，主线程每帧问询占用采样（最大值/均值）：**主线程 ≤16ms/帧（无 UI 卡顿）实测记录**。

## 验收状态（2026-09-25）

**引擎层 headless 记录已落地**（`tests/TestPerfAnchors.cpp`，合成 8000×6000 F32 缓冲，Release 实测）：
- 1920 精帧渲染（`renderPreview` target 1920×1440，默认调整 + 代表性主滑块，3 次取稳态）：**min ≈99ms / avg ≈100ms**（本机沙箱）。
- 结论：此为引擎渲染段基线，**非**锚点判定。B-2 ≤80ms 的松手→精帧口径还需叠加 UI 触发/调度与真机算力，须**真机（含独立 GPU）**验收，当前标 **真机待验**。
- B-3 主线程 ≤16ms/帧为 UI/主线程帧预算审计，headless 无界面对话框可测，仅保留审计点（PreviewWorker 已保证 histogram/渲染在 worker 线程），标 **真机待验**。
